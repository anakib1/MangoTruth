System code-name MangoTruth 

System contains two main three main parts - python framework (detectors), worker execution service based on kafka (called compute) and designed for distributed, robust and high-load environment and web server part that provides user UI, administrative UI and REST api for clients. System aims to be used for universities, institutions and to be open-source, community maintainable and extendable.

The detectors framework aims to solve the following tasks:

`datasets` - provide access to unified datasets in Ukrainian with easy access and extensibility. Looks like datasets.get_data('xlsum') -> dataset
`models` - provide access to unified models with easy access and extensibility. Looks like: models.get_model('ghostbuster'). We developed several state of the art models in Ukrainian. 
`evaluate` - provide option to evaluate particular model on particular dataset. evaluate(model, dataset) -> EvaluationReport with most common metrics (Precision at recall, TPR@1% FPR, accuracy ,recall etc )
`train` - provide option to train any model on any dataset if the model supports training procedure. All built-in models support this. 

Used datasets include: 

Data is generated by cropping text and asking language model to complete it. By selecting words and removing them from text, by asking ai model two rewrite text, to answer questions etc. Different temperature paramters were exploited.
- The xlsum dataset is used for AI plagiarism detection. It contains questions (prompts) and answers (outputs) generated by humans and various AI models (e.g., LLaMA 3, LLaMA 3.2, GPT-4, GPT-4o), along with a label indicating whether the response is human-written or AI-generated.
- The aya dataset is used for AI plagiarism detection. It contains educational questions and answers written by humans and AI models, with a label indicating the source. It helps detect whether a response is human- or AI-generated.

Used models include - perplexity based classification models (based on histograms, linear regreіssion, rule-based etc), ghostbuster based mode, dna-gpt model, ro-berta tuning models. We provide results up to 97% f1 on roberta tunes - first ever reported ukrainian results in ai plagiarism detection.

Used metrics include tpr at 1%/0.1 FPR, f1, accuracy, recall, precision.

The compute framework written in python places an easily extendable workload. All requests are routed through kafka workers to any available workers and central router determines the priority and speed of request and manages returns as well. Failure of any worker or router does not affect system

Web framework written in go support administrative access like enabling/disabling a model , adding new compute requests, managing quotas and users as well as user-friendly UI. This framework is focused on high performance, easy accessibility and data robustness and auditability.
